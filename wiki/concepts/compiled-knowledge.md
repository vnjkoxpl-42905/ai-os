# Let each source and useful answer improve the next answer

Compiled knowledge is a maintained explanation built from preserved sources, rather than a fresh reconstruction from those sources for every question.

When a source adds evidence, update the existing concept page, keep its provenance, and link relevant pages. When sources conflict, show both claims and their evidence until the conflict is resolved. A question can produce a useful comparison or connection; file that result into the existing page, or create a distinct synthesis page if it deserves its own subject.

## Example in this vault

The [[wiki/sources/llm-wiki-pattern|idea-file summary]] preserves what the supplied source says. This page captures its reusable principle. [[system/schema/llm-wiki|The operating schema]] turns that principle into the actual rules for maintaining this vault. The source archive preserves the text behind all three.

The teaching [[corpus/index|corpus]] and [[students/README|student records]] retain their own homes and authority boundaries. Operational claims about scheduling, payment, or published content must still be verified against the live systems.

## What this changes

Read the [[wiki/index|content index]] first for knowledge questions. Read the relevant compiled pages next. Return to raw evidence when a claim needs verification or the pages are incomplete. Save durable findings with sources; do not promote every chat message or unverified inference into fact.
