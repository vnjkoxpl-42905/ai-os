# Prototype a 3D concept before building it in Blender

**Source:** GPT 6 Astra + Blender = INSANE 3D Websites. Author: Chase AI. [Original video](https://www.youtube.com/watch?v=RhGiG-yZP-c). Publication and capture dates unknown. Ingested 2026-10-24.

**Evidence:** [preserved complete clip](../../raw/sources/clips/astra-blender-web-design-chase-ai/source.md), [provenance and hash](../../raw/sources/clips/astra-blender-web-design-chase-ai/PROVENANCE.md). Status: captured and text-compiled, not independently tested.

## What the source says

- Step zero (1:02) names Blender, Blender Agent Studio and a Blender-to-web skill as prerequisites. The narrator says a companion repository holds prompts, but the saved description does not provide its exact URL.

- At 1:55–3:39 he first generates multiple image concepts, selects an aesthetic, and only then uses it as a Blender reference. This reduces the cost of exploring geometry in the 3D tool.

- At 4:05–5:14 he uses scripted Blender work, inspects and iterates, then previews a Three.js version in a stand-in hero. The claimed 12 minute 40 second build is one narrated run.

- At 6:13–8:20 he distributes one interactive asset through a page narrative rather than leaving it isolated in a hero. Page mockups precede full implementation.

- At 6:51 and 8:38–9:24 he recommends a static mobile alternative, download-size measurement, hardware-level checks and pausing rendering when offscreen. The model-hosting feature is presented for sharing a prototype, not production.

## Application here, separated from source claims

Concept-first exploration and performance budgets transfer directly to dashboard polish. Real-time 3D is optional and should earn its place through useful student feedback or information, rather than becoming a decorative prerequisite.

## Actionable proposals

- If interactive 3D is desired, locate and inspect the exact companion repository and skill licence before installing Blender Agent Studio/Blender-to-web.
- Prototype multiple still concepts before committing to a 3D build.
- For any accepted 3D component, measure transfer size, pause offscreen rendering, test weaker hardware and supply a mobile/static fallback.
- Keep prototype sharing distinct from production hosting.
