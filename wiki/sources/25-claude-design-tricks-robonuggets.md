## What the source says

### Reference-led systems

The creator recommends extracting a system from owned assets or a reference, shortlisting three systems, naming suitable fonts, studying competitor copy and mixing selected design principles (0:35 to 3:57). He says a local Code skill can hold a system when web Design lacks direct local-file access.

### Resources and polish

Intermediate tips cover external image/video generation, previous projects, annotated reference libraries, Impeccable, voice guidance, 21st.dev, React Bits, Canvas UI, coherent icon packs, editable SVG, Lordicon and Creators Toolbox (4:57 to 9:48). Counts, free-access descriptions and capabilities remain dated source claims; licences and accounts need separate verification.

### Advanced workflows

Advanced tips cover selective Apple HIG guidance, GSAP, Code Design artboards, a slider-based tweak panel, word-timestamped transcript animations through Hyperframes, and a searchable reusable design asset index (10:15 to 12:39). The captured text does not include the full prompts shown on screen. The existing PDF resource map already records decisions on all 25 tips; this transcript adds preserved, searchable evidence rather than another installation mandate.

## Application and limits

For the student dashboard, use concrete component references and a visible target, keep the approved charcoal/near-white system coherent, compare meaningful alternatives and inspect actual rendered motion. A clip does not justify adding every effect or tool. Joshua's existing voice and product decisions take priority over generic marketing prescriptions. These are application judgments, distinct from source claims.
