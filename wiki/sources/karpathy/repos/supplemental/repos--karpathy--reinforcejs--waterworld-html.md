## Reviewed content

WaterWorld UI presents a 152-dimensional agent-relative sensor state, four thrusters, moving apples/poison and contact rewards. Canvas can hide globally visible objects to expose the agent view; a human can join using arrow controls and compare reward histories. Adjustable DQN settings, exploration and pretrained loading support experimentation. Static HTML/script/prose read; no gameplay or training run. Editable agent settings use eval and legacy HTTP dependencies, so this is historical demo evidence rather than imported operational code.

> The optimal strategy of the agent is to cruise around, run away from green targets and eat red targets. What's interesting about this demo is that the state space is so high-dimensional, and also that the sensed variables are agent-relative. They're not just toy x,y coordinates of some fixed number of targets as in previous demo.
