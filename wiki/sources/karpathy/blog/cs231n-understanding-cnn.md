## What this source says

These draft course notes survey activation/filter visualization, maximally activating examples, representation embeddings, occlusion experiments, gradients, feature inversion and adversarial examples. They note that persistent zero activation can indicate dead filters, and caution that individual neuron axes need not have standalone semantic meanings. Sliding occlusion explores which input regions affect a class score.
