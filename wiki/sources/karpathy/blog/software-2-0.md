## What this source says

Karpathy frames learned weights as a different software representation: a dataset specifies desired behavior, an architecture constrains the program search and optimization determines parameters. Much of development then moves to collecting and cleaning examples while surrounding code manages training and inspection. He lists potential hardware, portability and compositional benefits, but also interpretability, bias, silent failures and adversarial examples as limitations. He argues for dataset-oriented tooling alongside traditional programming tools.
