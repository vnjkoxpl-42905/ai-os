## What this source says

Karpathy describes building a menu-to-food-image app with Cursor and Claude. A local UI appeared rapidly, but deployment required API documentation, keys, rate-limit handling, production authentication, DNS and payments configuration. He caught an incorrect email-based payment/account association and switched to stable user identifiers. The first version lacked persistent work storage and queues, so refreshes and long requests could lose results. He proposes simpler or preconfigured systems and interfaces that agents can operate, including CLIs and Markdown documentation.
