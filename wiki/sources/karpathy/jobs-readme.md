## Interpretation and limits

This source supports keeping original evidence, derived model judgments and practical conclusions separate. Occupation descriptions are third-party BLS material, not Karpathy's personal prose or opinions. This README summary does not ingest those descriptions or validate scoring quality. The live demo, data freshness, API availability and pricing were not verified; setup commands were not run. No occupational prediction is adopted into Joshua's decisions.
