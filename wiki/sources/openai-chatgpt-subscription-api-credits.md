# API credits for eligible ChatGPT subscribers

[OpenAI's video](https://www.youtube.com/watch?v=ujmyzWSj8IU) describes subscription-linked API credits and demonstrates building an app with the OpenAI Developers plugin in Codex. The clip's publication and capture dates are unknown. [Preserved transcript and provenance](../../raw/sources/clips/openai-chatgpt-api-credits/PROVENANCE.md); video completeness was not independently verified.

## What the source says

Eligible Pro and Business subscribers can link an API organization via billing and receive credits. The demonstration uses Decisions and Responses APIs in a writing assistant. It suggests the OpenAI Developers plugin to build an API integration; it does not establish that Joshua's account is eligible or linked.

## Official guidance checked 2026-10-29

[OpenAI's API credits guide](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) states that eligible paid Pro and Business plans must be at least seven days old; the subscription and API organization must share an email, and the claimant must own both. Pro tiers receive $100, $200 or $500 per billing cycle; Business gets $20 per Standard or $100 per Premium paid seat, capped at $500 per monthly workspace cycle. Annual Business billing has a yearly grant. The first grant is prorated. Unused monthly grants expire at cycle end. Credits are linked to one API organization and used via its project API keys.

The guide covers Responses, Decisions, Agents, voice, images and built-in tools. The benefit does not cover Codex usage through API keys or increase signed-in Codex/ChatGPT limits. Purchased credits can be consumed after free credits are exhausted. Joshua's entitlement, organization, balance and recharge settings remain unverified.

## Practical next step

Open ChatGPT Settings > Billing or API Platform Billing, check eligibility and choose the intended organization before confirming. Then check billing and usage; use the [OpenAI Developers plugin](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) to build a small API-backed tool. Follow existing secret and student-data rules. See [AI workspace hub](../../references/ai-workspace/index.md) and [action queue](../../references/ai-workspace/action-queue.md).
