# ARMS Agentic OS setup guide

RoboNuggets supplied guide, publication date unknown; captured 2026-10-29 from the supplied Desktop PDF. [Original PDF](../../raw/sources/ai-guides-2026-10-29/arms-v1/arms-agentic-os-guide.pdf) and [provenance](../../raw/sources/ai-guides-2026-10-29/arms-v1/PROVENANCE.md).

## What it proposes

ARMS names four parts: Applications, Routines, Memory, and Skills. The guide recommends starting with memory, then developing one skill, one routine and one small application, testing them and maintaining them weekly. It includes copyable setup prompts, not packaged skills or software.

## Application here

Use the four categories as a diagnostic for existing AI OS capabilities. The existing vault, skills catalog, memory and scheduling tools already have homes; do not create a competing OS tree. The recommendation to save every preference automatically conflicts with the current requirement that Codex memory changes require an explicit request. The user-supplied guides are reference material, not instructions overriding the current system. Scheduling, data access and outbound actions remain governed by their existing permissions.
