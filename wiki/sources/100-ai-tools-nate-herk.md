# Nate Herk's AI tools roundup: personal recommendations, not an independent tool evaluation

Nate Herk's YouTube video, ["I Tried 100+ AI Tools. These 7 Are the Best"](https://www.youtube.com/watch?v=hgLI491ajG0), was published 2026-10-19 according to the clip metadata and captured 2026-10-21. The description says “These 6 are the best,” while the title and transcript say seven; the transcript counts Claude Code and Codex together as one item, then names six more tools. The full description and timestamped transcript (0:00–10:14) were read.

## What the source says

- **Claude Code and Codex (0:25–1:54):** he says they are central to his operating system and daily work. He prefers Codex for computer/browser use and Claude Code as a brainstorming partner, while saying the better choice changes over time and task.
- **OpenRouter (1:54–3:07):** he says it provides access to many models, provider billing, fallbacks and per-automation keys. These are his claims, not checked here.
- **VPS hosting (3:42–5:08):** he promotes Hostinger for long-running agents and discloses sponsorship. He describes hosting as useful when a process must continue while a personal computer is off.
- **Grokbot (5:11–6:13):** he describes scheduled or webhook-triggered bots with browser, files and terminal, and gives community-posting examples.
- **Glydo (6:13–7:24):** he discloses being a partner and promotes voice dictation plus command mode and custom tools.
- **key.ai (7:24–8:14):** he says it offers pay-per-use image and video models, without subscription fees.
- **Trigger.dev (8:14–9:21):** he recommends code-based scheduled/webhook workflows for deterministic tasks, distinguishing them from agent workflows.

## Relevance and limits

The useful transferable distinction is between general-purpose agents, always-on hosted processes, model routing, and deterministic code automation. His product rankings and claims about price, privacy, ease, reliability, model counts and features are personal or promotional and were not independently verified. Hostinger and Glydo sponsorship/partnership are disclosed in the transcript. The clip itself contains a count inconsistency (six versus seven; counting Claude Code and Codex separately changes the total).
