# Use the Mobbin sample to compare specific interface screens

Joshua supplied the [Mobbin UI Sample Pack](../../raw/sources/mobbin-sample-pack-100/mobbin-sample-pack-100.zip) on 2026-10-29. Its publication date is unknown. The archive contains 100 WebP screenshots and a [README](../../raw/sources/mobbin-sample-pack-100/README.txt); the [provenance record](../../raw/sources/mobbin-sample-pack-100/PROVENANCE.md) states each extracted file was checked against the archive bytes. The README describes 50 mobile and 50 desktop examples, sampled from a larger collection, and claims each is a different app.

## Rights and limits

The supplied README says Mobbin curated screenshots of other companies’ copyrighted interfaces for personal design reference and inspiration, and says not to resell or republish them as one's own work. It says images carry a Mobbin watermark. The pack supplies neither per-image source URLs nor a separate license. Do not infer permission to redistribute or use the screenshot assets in a product; check the relevant rights for any intended use beyond reference.
