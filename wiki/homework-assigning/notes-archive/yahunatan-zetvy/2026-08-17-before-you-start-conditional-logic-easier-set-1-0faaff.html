The same claim, said backwards

Read this before you open Conditional Logic (Easier) Set 1. It picks up exactly where the first set left off.

There is exactly one legal way to flip it

Set 4 taught you the arrow only runs one way. That is true, with one exception, and it is the single most useful move in this part of the test.

You can reverse a conditional if you also negate both halves. Reverse and negate together, never one without the other. The result says the identical thing as the original. It is not a new fact. It is the same fact wearing different clothes, which is why the correct answer is so often hiding in it.

rain → the ground is wet

the ground is not wet → it did not rain

Both sentences are one claim. If dry ground were possible after rain, the first promise was never true to begin with.

Reversing without negating is the error. Negating without reversing is the same error from the other side. The two moves travel together.

Two phrasings that trip almost everyone

"Only if" points at the necessary half. It looks like "if" and behaves like its opposite. "You may enter only if you have a ticket" does not promise that a ticket gets you in. It promises that without one, you are not getting in.

enter → ticket

"Unless" means "if not." Take whatever follows the word unless, negate it, and make that your trigger. "We will go unless it rains" becomes: if it does not rain, we go.

no rain → we go

Do not try to feel your way through these two. Translate them mechanically, on the page, and then reason about what you wrote. The intuition comes later and it comes from the reps.

While you drill

  1. Diagram the stimulus, then write the flipped version underneath it before you read the choices.
  2. When you meet "only if" or "unless," translate on paper. Do not translate in your head.
  3. If a choice reverses the arrow, check whether it negated both halves. If it did not, it is out, and you can stop reading it.

This set steps up from Set 4, so expect it to feel harder. That is the design, not a signal that something has gone wrong. Blind review the misses before you check anything.
