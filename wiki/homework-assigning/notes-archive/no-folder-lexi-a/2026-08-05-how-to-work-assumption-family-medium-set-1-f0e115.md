# Assumption Family (Medium) Set 1

**10 questions. Negation practice.**

Every question here is an assumption question, and all ten were chosen because **Too Strong** is the trap that catches most people on them. That is the rule from our session: soft language is easy for an author to be committed to, so it is easy for an argument to require.

Run both steps, every time:

1. If this were true, does the argument get stronger?
2. Negate it. Does the conclusion collapse, or does it only wobble?

Remember that negating means stepping outside the category, not flipping to the opposite. And when you are down to two, ask which one is the safer claim.
