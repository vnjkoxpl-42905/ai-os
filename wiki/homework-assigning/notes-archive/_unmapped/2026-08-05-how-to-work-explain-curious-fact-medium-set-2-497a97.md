# Explain Curious Fact (Medium) Set 2

**20 questions. This is the bulk of the work.**

Phenomenon questions were the third thing we flagged. The pattern is always the same: you are handed a result, and you need the answer that actually accounts for it.

The trap that dominates this set is **No Impact**. A choice sits next to the topic, sounds informed, and changes nothing about why the result happened. That is the same test as an objection answer in the flaw manual: assume it is true, then ask whether it does real work.

One habit for this set. Before you look at the choices, say out loud what needs explaining, in one sentence. If you cannot say it, you are not ready to judge an answer.

This drill draws a fresh set each time you open it, so it is the one to repeat.
