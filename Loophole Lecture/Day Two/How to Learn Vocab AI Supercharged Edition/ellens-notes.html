How to Write a Definition of a Vocab Word (For Non-Native English Speakers)

  1. Look up your native language definition and the English definition.

    1. Use Google or an AI to do this.

  2. Combine these two sources with the original sentence to understand how the word was used.

  3. Write your own 1-4 word simple definition that combines all the information into an easy-to-remember format

  4. This definition must be in English.

  5. Write 2 sentences of your own using the word.

    1. You can use AI to help you speed up this process, but remember the time you spend with these words will increase your level of mastery. This is something you want to spend time on.

How to Write a Definition of a Vocab Word (English only)

  1. Look up the definition on Google.

  2. Combine the definition with the context provided by the original sentence to understand how the word was used. 

  3. Write your own 1-4 word simple definition that combines all the information into an easy-to-remember format.

  4. Write an example sentence with the word.
