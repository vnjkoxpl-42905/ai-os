## Operating Standard for New Lecture Ingestions

Whenever a new Loophole video lesson is ingested:
1. Create a dedicated topic subfolder under `Loophole Lecture/<Concept Name>/`.
2. Extract the verbatim transcript and timestamp milestones into `<concept>-transcript.md`.
3. Capture visual whiteboard frames into `<Concept Name>/images/`.
4. Draft a teleprompter script with production cues into `<concept>-teleprompter.md`.
5. Create `<Concept Name>/README.md` as the local subfolder router.
6. Register the new subfolder in this master index table.
