## Operating standard for new lecture captures

Capture only the requested artifacts. Preserve native wording, timestamps, source identity and capture limitations. Keep written page notes separate from spoken captions, and distinguish automatic extraction from human listening verification. Add a local README and routes from the owning subject hub and complete source catalog. Preserve original bytes; never overwrite a different generation. Produce adaptations, new frames or media downloads only when requested.

The five RC batches contain 59 lectures and 28 captured written-note sections. Camo is an additional transcript-only lecture. The older Sufficient Assumption package remains available with its historical accuracy claims explicitly unverified. Planned topics above are not claims of completed captures or existing folders.
