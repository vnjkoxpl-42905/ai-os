Answer Choice Translation Primer

  1. First, complete 3 sections Written Answer Choice Translation Spreadsheet.

  2. Second, complete 3 sections Outloud Answer Choice Translation Drills (just like Translation + CLIR, but only answer choices).

NOTE: Do not reuse the same sections for the Written Answer Choice Translation Spreadsheet and Outloud Answer Choice Translation Drills. Do not combine the Primer with other drills.

Written Answer Choice Translation Spreadsheet

  1. Read only the answer choices in the section.

    1. Do not read the stimulus.

    2. Do not read the question stem.

  2. Write down each individual answer choice.

  3. Write down a Translation of each answer choice.

    1. This means read A, write the literal text of A, and write the Translation of A. Then repeat the same process on B, C, D, and E.

Outloud Answer Choice Translation Drills

  1. Read only the answer choices in the section.

    1. Do not read the stimulus.

    2. Do not read the question stem.

  2. Translate the answer choice out loud.

  3. Quip the answer choice out loud.

    1. This means read A, translate A, and quip A. Then repeat the same process on B, C, D, and E.
