Answer Choice Translation Primer

First, complete 3 sections Written Answer Choice Translation Spreadsheet.

Second, complete 3 sections Outloud Answer Choice Translation Drills (just like Translation + CLIR, but only answer choices).

NOTE: Do not reuse the same sections for the Written Answer Choice Translation Spreadsheet and Outloud Answer Choice Translation Drills. Do not combine the Primer with other drills.

Written Answer Choice Translation Spreadsheet

Read only the answer choices in the section.

Do not read the stimulus.

Do not read the question stem.

Write down each individual answer choice.

Write down a Translation of each answer choice.

This means read A, write the literal text of A, and write the Translation of A. Then repeat the same process on B, C, D, and E.

Outloud Answer Choice Translation Drills

Read only the answer choices in the section.

Do not read the stimulus.

Do not read the question stem.

Translate the answer choice out loud.

Quip the answer choice out loud.

This means read A, translate A, and quip A. Then repeat the same process on B, C, D, and E.
