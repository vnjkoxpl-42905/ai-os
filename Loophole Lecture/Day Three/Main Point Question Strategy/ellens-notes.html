RC Main Point

  • Ask yourself, "What did the author want me to take away from this passage?" The Main Point is what the author wants you to take away from the passage

    • You want the result of the work as opposed to all the work listed out

    • The Main Point is not a summary of the entire passage's contents 

    • The Main Point is not guaranteed to be written out in the passage 

    • The Main Point is not necessarily more likely to be mentioned in the last paragraph or the first paragraph. 

  • If the author had 10 seconds to elevator pitch you their passage, is this answer choice what they would say? That's the Main Point.

  • If the author has an opinion in the passage, it's got to be in the Main Point.

  • Beware of choosing a premise in the Main Point question. These are just the building blocks that add up to the takeaway.

  • Always Main Point every passage you read, including each comparative passage as soon as you're finished with each one (Main Point Passage A before reading Passage B)

  • You can use the Conclusion Test on Main Point in RC: Because [main point answer choice 1], we know that [main point answer choice 2]. Switch the order and see which configuration makes sense. The Main Point answer that makes sense in the "we know that" spot is likely the correct answer.
