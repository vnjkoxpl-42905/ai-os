RC Organization Question Process

  1. Read and translate the first part of every answer choice

  2. Ask the piece of the answer you read, "Did this happen?"

    1. If the item you read did happen in the passage, just go to the next answer choice without reading the rest of the answer.

    2. If the item you read did not happen in the passage, read and translate the rest of the answer choice. Decide if you want to cross it off or give it a pass to the next round.

  3. Proceed to the next piece of the answer, only reading the answers that are still in the running.

  4. Repeat this on every part of the answer choice.

  5. As you get into the later pieces of each answer, evaluate whether the answer so far (including previous pieces) matches what happened in the passage, taking into account the order of how the passage was structured.

  6. Repeat until you sorted every answer. Only choose an answer once you've vetted all the text of that answer.
