Joshua's AI operating system is the Obsidian vault at `C:\Users\Joshu\dev\ai-os` — 7,869 markdown files, 2.5 GB. It holds `context/`, `wiki/`, `students/`, `corpus/`, `decisions/`, `brainstorms/`, `handoffs/`, `distillates/`, `research/`, `projects/`, plus the skill catalog under `skills/claude` (179) and `skills/codex` (154), governed by `skills/PARITY.md` and `skills/INDEX.md`.

**Why:** On 2026-09-07 a smaller duplicate was scaffolded at `OneDrive\Desktop\OS` because the initial check looked only at Desktop and the home folder, not `dev/`. That duplicate is a beginner-level version of a system he had already outgrown. Two vaults is worse than one.

**How to apply:** Treat `dev/ai-os` as the only source of truth and build on what is already there rather than creating parallel structure. Two standing caveats: the vault is **not under git and has no backup**, and the LSAT U repo still carries stale Mac paths (`/Users/joshuaf/...`) that do not resolve on this Windows machine.
