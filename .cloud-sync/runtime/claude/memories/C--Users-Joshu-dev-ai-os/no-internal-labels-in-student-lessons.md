Joshua explicitly corrected this on 2026-09-30: never show "concept lesson" in student-facing notes, lesson titles, headings, badges, or preview pages. That is an internal description of how the material was made.

Use a title and headings that teach the actual reasoning. Keep draft/version metadata, source-production labels, and design commentary in private records rather than the student's lesson.

Apply this to post-session recaps and reusable LSAT teaching pages, including generated HTML. Check the rendered opening, not only the Markdown source.
