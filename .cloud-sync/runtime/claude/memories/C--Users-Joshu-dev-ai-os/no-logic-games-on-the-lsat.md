Never mention, offer, or ask about Logic Games / Analytical Reasoning / "LG". The current LSAT has two section types only: Logical Reasoning (LR) and Reading Comprehension (RC).

**Why:** Joshua said so on 2026-09-11 after being asked whether a feature should cover LG: "never ever mention LG logic games. That doesn't exist on the LSAT." Bringing it up reads as not knowing the test he teaches.

**How to apply:** When enumerating section types, say "LR and RC". Never add an LG option to a question, a UI, a schema, or copy. Related: [[no-door-metaphor-in-student-copy]].
