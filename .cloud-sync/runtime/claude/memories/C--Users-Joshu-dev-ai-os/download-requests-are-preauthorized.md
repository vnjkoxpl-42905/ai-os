---
name: download-requests-are-preauthorized
description: Joshua wants download requests carried out without a separate permission question.
metadata:
  type: feedback
---

When Joshua explicitly asks to download a specific item, treat that request as authorization to download it and do not ask a separate permission question for the download. This preference does not override action-time confirmation requirements for installs or changes that grant sensitive access, accept legal terms, or materially change security permissions. For an extension such as a password manager, ask only for the required confirmation at the point of installation and explain the access it grants.
