Claude Code lists every skill by name but shows descriptions only within `skillListingBudgetFraction` × context (default 0.01, 30,000 chars here), ranked by usage × weekly half-life, then A to Z with home skills before vault skills. On 2026-10-12, 403 skills wanted 126,322 chars and core skills such as `transcript-intake` and `post-session-recap` were names only. The vault `.claude/settings.json` now sets the fraction to 0.015 plus `skillOverrides`: 69 vendor skills `user-invocable-only`, and 183 never-used skills `name-only`, including Expo sub-skills behind `expo-overview`. The settings are generated by `audits/skills-2026-10-12-karpathy/listing_overrides.py` from `name-only.json`.

**Why:** A never-used skill gets no description, so it cannot trigger, so it stays unused. Raising the budget alone gives the extra room to whatever sorts next alphabetically, not to core skills.

**How to apply:** After installing a skill pack, run `claude -p "OK" --debug-file <file>`, search the log for "Skill listing over budget", and rerun the generator if core skills lose their descriptions. Take a skill off `name-only.json` once it is in use. Plugin skills cannot be overridden. "Never used" was measured on the Windows laptop only. Related: [[home-skill-copies-shadow-vault]].
