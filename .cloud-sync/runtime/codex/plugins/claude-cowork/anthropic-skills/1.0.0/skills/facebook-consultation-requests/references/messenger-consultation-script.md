# Messenger Consultation Script

The reply Joshua sends to LSAT service requests on Messenger. Shorter and more casual than email, but same idea: warm acknowledgment, the free consultation as the next step, the booking link, what the call covers, and a fallback contact. Always personalize to what the person actually said.

**Link:** https://cal.com/joshua-jtx5ud/consultation
**Fallback email:** contact@aspiringattorneys.com

## Base message (Joshua's actual Messenger wording)

> Hey {{first_name}},
>
> Hey yes! You can schedule a free consultation session to see if we are a good fit:
> https://cal.com/joshua-jtx5ud/consultation
>
> We'll use the call to talk through where you're at, what score you're aiming for, and whether we'd be a good fit working together.
>
> If you have any trouble booking you can email me at contact@aspiringattorneys.com

## Personalization

- Open by reacting to their message ("Hey yes!", "Thanks for reaching out", "Great to hear from you").
- If they mentioned a score, timeline, plateau, or platform, mirror it in one short line before the link ("A September test gives us a solid window").
- Keep it casual and brief, Messenger tone, not a formal email. Contractions, no em dashes.
- If they only said "interested" with no detail, the base message is fine as-is.

## Rules

- Type into the message box, do not send until Joshua approves.
- One person at a time unless told otherwise.
- Never send to a group chat.
- If they already have the link or already booked, don't re-send; tell Joshua instead.
