216-
217-1. **Scrape** a URL with `POST /v2/scrape`. The response includes a `scrapeId` in `data.metadata.scrapeId`. If you want persistent browser state, pass `profile` on this request.
218-2. **Interact** by calling `POST /v2/scrape/{scrapeId}/interact` with a `prompt` or with playwright `code`. Do not pass `profile` here; the interact session inherits the profile from the scrape job.
219-3. **Stop** the session with `DELETE /v2/scrape/{scrapeId}/interact` when you’re done. For writable profiles, changes are saved when the session stops.
