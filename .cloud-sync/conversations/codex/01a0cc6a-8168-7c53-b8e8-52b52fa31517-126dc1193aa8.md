## assistant

Research delivered to the parent agent with current official Lovable and Supabase sources.

The decisive finding is that Lovable Cloud does not support a one-click or documented zero-downtime migration to an owned Supabase project. Lovable’s supported export omits usable passwords, Storage files, Edge Function code, and secrets. A safe migration therefore requires a staged rebuild, final write freeze, data import, separate file transfer, auth password resets, service reconfiguration, verification, and controlled cutover.
