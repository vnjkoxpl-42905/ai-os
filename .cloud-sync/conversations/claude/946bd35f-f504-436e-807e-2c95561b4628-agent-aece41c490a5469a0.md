## 5. The bed, and why it cannot read as anxiety

Three sines at **110 / 165 / 220 Hz** (fundamental, fifth, octave) at weights 1 / 0.50 / 0.35, `lowpass=f=400:poles=2`, `volume=-14.7dB`. Harmonically fused, so it is one pitch rather than a chord and reads as air, not scoring. 110 Hz would vanish on laptop speakers; the 220 Hz partial carries it. `afade` in **0.40 s**, out **0.12 s**, ending 0.12 s after the last interior sample — the bed arrives under the thought and is gone before he opens his mouth, without a click on a low sine.

One span per **maximal run** of interior utterances, so it does not dip in the 320 ms between two Chunks read back to back. Seven spans across the film, 3.02 to 15.24 s.

The guarantee is measured, not asserted. `verify-bed.mjs` checks five things, and a missing measurement fails (an earlier draft reported PASS across a row of `NaN`):

```
Q1 spans 4.88s / 3.02s / 14.73s   flat within 0.00 dB
Q2 spans 15.24s / 13.77s          flat within 0.00 dB
Q3 spans 12.17s / 4.22s           flat within 0.00 dB
bed -36.2 / -36.0 / -36.1 LUFS, 15.6 / 15.3 / 15.8 LU under voice, 42.5 dB down above 400 Hz
```

Anxiety is made of periodicity and rising parameters. Amplitude, pitch and cutoff are the same constants in every span, so nothing can pulse or build; no span exceeds 20 s, so no drone has room to accumulate; and the 400 Hz ceiling means it can never acquire a bright edge or mask the 1-4 kHz band intelligibility lives in.

Two traps here. **Never gate one long tone with chained afades** — `afade=out` holds zero for the rest of the stream and a later `afade=in` holds zero before its start, so four fades multiply to a completely silent bed with exit code 0. One clean file per span, delayed into place with `adelay=...S`. And `astats` frames a 55 Hz-fundamental signal at 4.69 periods and manufactures 1.25 dB of variation out of a provably constant one; the gate windows at 9600 samples (exactly 11 periods) and trims to whole windows, and the same measurement then reads 0.00 dB.

## Six traps found the hard way

1. **`spawnSync(..., {shell: true})` concatenates argv unescaped on Windows.**
   Passing a sentence inline made cmd.exe split it on spaces, Kokoro spoke the
   first word only, and the CLI still returned `ok:true` with a 0.66 s WAV.
   Ten utterances were silently wrong before the duration check existed.
   The text goes through `--text-file`. Never inline it.
2. **The concat demuxer's `outpoint` rounds a gap up to a packet boundary** -
   measured +68 ms on a 700 ms gap, which would put the film about 3 s out by
   the end. Utterances are padded by an exact sample count with
   `apad=pad_len=`, and the total is asserted.
3. **Chained `afade` filters multiply into digital silence.** `afade=t=out`
   holds zero for the rest of the stream and a later `afade=t=in` holds zero
   before its start, so gating one long tone with four fades produced a
   completely silent bed and exit code 0. One clean file per span, delayed into
   place, is the only version that survives.
4. **`astats` frames a 55 Hz-fundamental bed at 4.69 periods** and manufactures
   1.25 dB of variation out of a provably constant signal. `verify-bed.mjs`
   windows at 9600 samples, exactly 11 periods, and trims to a whole number of
   windows. The same measurement then reads 0.00 dB.

5. **`initial_prompt` makes Whisper skip the opening it was primed with.**
   Seeding the decoder with the text it is about to hear cost 10 of 17 words on
   `Q3-002-i` and reported them missing. The audio was perfect. Decode clean
   synthesis unprompted.
6. **Whisper normalises orthography nobody asked it to.** It writes `gonna` as
   `going to` and `Rexx` as `Rex`, so demanding equal token counts failed four
   utterances whose audio was correct. The gate aligns instead and judges the
   SHAPE of the miss: isolated unaligned tokens are orthography, three or more
   in a row is truncation. Eight tokens across the whole film are timed by
   interpolation; every one is an orthographic difference.

An earlier draft of `verify-bed.mjs` also reported PASS across a row of `NaN`
because ffmpeg was writing to a stream it was not reading. A missing
measurement now fails.

Whisper never supplies a word. Captions carry the token from `script.json` with
Whisper's clock, so the caption cannot disagree with the paper card.

## The two layers

Verbatim Chunk reads are the interior monologue. Everything he says out loud -
the rephrase, the Colouring In, the false starts, and all of The Recall - is in
the room. The DSP, the level and the bed all switch at that boundary, and the
switch is the lesson.

Relative levels, set once and anchored by the master pass:

| Layer | Offset | Why |
|---|---|---|
| room | 0 LU | the reference |
| interior | -3.5 LU | thought is quieter than speech |
| fragment | -2.5 LU | a false start is thrown away, not delivered |
| bed | -16 LU | felt, never heard |

Master: `loudnorm=I=-19:TP=-1.5:LRA=9:linear=true`. Measured on Q1: -19.0 LUFS,
-1.5 dBTP.

// property is what makes synthesis sound synthetic: people breathe at clause
// boundaries. Any aloud part over MAX_BREATH words is split at the comma
// nearest its midpoint, with 180 ms of air between the halves. Punctuation
// only - no word moves, nothing is added, and the gate still passes.
const MAX_BREATH = 32;
function breathe(part) {
  const w = part.text.split(/\s+/);
  if (w.length <= MAX_BREATH) return [part];
  const commas = [];
  w.forEach((x, i) => { if (/,$/.test(x) && i >= 7 && i <= w.length - 9) commas.push(i); });
  if (!commas.length) return [part];
