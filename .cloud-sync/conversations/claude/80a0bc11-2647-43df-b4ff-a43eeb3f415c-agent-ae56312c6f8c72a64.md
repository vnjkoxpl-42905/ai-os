PT156 is already partially in the bank: `/data/PT156-S2-LR.json` and `/data/PT156-S4-LR.json` exist (lines 477–478 of `questionLoader.ts`), but **not** S1 or S3. So "PT156, LR section" launches today only for whichever sections of PT156 are present in that list — and it's the student who navigates to `/testing` and picks it, not a teacher pushing an assignment.

**2. No teacher-assign path reaches this bank.** `src/lib/assignWork.ts` only knows four `AssignableItem` kinds: `homework_set` (row in `homework_sets`), `guided_drill` (row in `guided_drills`), `activity` (row in `activities` — the `activity_assignments` insert at line 269–317 does `.from('activities').select('*').eq('id', item.activityId).single()` and **throws if the id doesn't exist**), and `bootcamp` (static `BOOTCAMPS` list). None of these take a raw PT/section number — all require a pre-existing DB row or a pre-authored content JSON like the 12 seeded `read-recall-colour-pt*.json` files in `src/features/activity-centre/content/`.

**3. `activity` requires an existing `activities` row — no ad hoc PT/section assign.** Confirmed above; there's no code path that synthesizes an `activities` row from a bare `{pt, section}` pair.

**Bottom line:** No teacher-facing "assign PT156 LR section" exists. The closest thing is the student self-serve Testing Centre, gated on that section's JSON file being present in `JSON_FILES`/the merged bank (PT156 S2/S4 only right now). To make PT156.S1/S3 assignable as a Read-Recall-Colour activity like the other 12, you'd need a new `read-recall-colour-pt156-sN.json` matching the shape above (`slug`, `title`, `source_section: "PT156.SN"`, `item_format: "spoken-recall"`, `items[]` with `slug`, `prompt`, `credited_answers`, `cumulative_after`, `explanation`) plus a row in the `activities` table pointing at it, registered in `src/features/activity-centre/content/index.ts`.
