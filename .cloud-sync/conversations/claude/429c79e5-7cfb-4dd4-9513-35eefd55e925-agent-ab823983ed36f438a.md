- Weekly plans | `pages/teacher/TeacherWeeklyPlans.tsx` | `weekly_plans`, `weekly_plan_items`, `schedule_templates`; links each plan item back with `update({classroom_item_id})` (line 351).
- Classroom notes/items | `createClassroomItem`. The MCP function (`supabase/functions/mcp`) also has `post_classroom_note`, `assign_homework`, `assign_passage_map_homework`, `send_note`, `list_students`, `find_students`, `get_assignment_status` and `list_homework_sets`.

**Editing, un-assigning and closing out**
- Edit | `updateClassroomItem(id, {status, due_at, …})`.
- Un-assign | `archiveClassroomItem` sets `status:'archived'` and `visible_to_student:false`. Used from `teacher/students/DossierWork.tsx` and `TeacherBootcamps.tsx`.
- Sync status from the source | `syncClassroomItemStatusBySource`.
- Close out a practice-test section | `src/lib/closeOutAssignedSection.ts` and `completeAssignedWork.ts` (both touch `homework_assignments` and `classroom_items`).
- Admin assignment list | `src/hooks/useAdminAssignments.ts`.

**Grading and review**
- AI TA drafts | `hooks/useAITADrafts.ts`, `pages/teacher/TeacherAITA.tsx`, `TeacherToday.tsx` | `ai_ta_drafts` select, then `update(patch)` by `id` for status or edited text.
- Activity responses | `features/activity-centre/api/activitiesClient.ts` | `activity_item_responses`.
- RRC grading | edge function `grade-rrc-section`; `sweep-rrc-grading` re-runs sections that never got a grade.
- Activity coaching | `activity-coach` judges free-text responses.
- Uploaded student work | `external_work_uploads` (`TeacherUploads.tsx`), parsed by `parse-external-work`.
- Question notes | `admin_question_notes` (`hooks/useAdminQuestionNote.ts`).

**Session notes and student context**
- Scan notes | `scan-session-notes` with `{action:"scan", …opts}`.
- Resolve a note | same function, `{action:"resolve", ledger_id, student_class_id}`.
- Discard a note | same function, `{action:"discard", ledger_id, discard_reason}`.
- Ingest one note by hand | `ingest-session-note`.
- Build the session bundle | `synthesize-session-bundle`; `src/lib/sessionBundleNotify.ts` then inserts into `messages` and `notifications`.
- Student context/dossier | `hooks/useStudentContext.ts` | `student_context` rows plus files in a storage bucket (upload, then update `file_path`; delete removes both).
- Other reads: `student_sessions`, `useStudentAnalytics` (`attempts`, `daily_stats`), `student_external_metrics`, `student_analytics_sources`.
