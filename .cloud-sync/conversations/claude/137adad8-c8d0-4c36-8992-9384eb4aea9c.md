276	## Patterns and systemic issues
277	
278	1. **Alpha-based muted text is the contrast bug.** `rgba(ink, 0.4)` cannot be reasoned
279	   about against a ground, and it is why one token breaks four separate places on one
280	   page. The dark theme resolved the same token to a real colour and passes at 8.27:1.
281	   The light theme should do the same. There is already a `--classroom-meta-text`
282	   defined for exactly this and it is unused at these call sites.
283	2. **The record and the code have drifted on typography, and nobody notices** because
284	   both faces are geometric sans and the difference is invisible at a glance. DESIGN.md
285	   already carries a "known gaps" appendix; this belongs in it either way.
286	3. **Route-level cost is invisible at the provider.** A shell-mounted provider means a
287	   text page silently pays a drill page's bill, and the only record of the cost is a
288	   comment that is now wrong by 4-6x.
