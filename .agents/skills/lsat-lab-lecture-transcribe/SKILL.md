# LSAT Lab lectures for live teaching

Joshua has stated that, as an LSAT Lab tutor, he is authorized to use and adapt the selected lectures. Capture only the selected lecture(s); this does not authorize library-wide collection or publishing. This skill handles video lectures; `lsat-lab-transcribe` handles written PrepTest explanations.

## Capture once, then assemble

1. Read the repository instructions and `wiki/teaching-voice.md`. Use the current approved browser skill and its documented tools. Reuse the selected LSAT Lab tab. In Codex, use CUA with the in-app browser; in another runtime, use its approved browser surface. Do not copy outdated CDP/Playwright instructions from older skills or guess media/caption URLs.
2. Verify the live title, instructor, lecture date, video ID, duration, and URL. Read the existing archive/index before creating anything. Home: `corpus/lectures/lsat-lab/<topic>/<lecture-date>-<videoid>/`. If the lecture date is unavailable, use `undated-<videoid>` and record that uncertainty.
3. Prefer the native full transcript/caption export, using supported UI/documented browser access. Preserve one full timestamped extraction and note whether captions are automated or authored. Check the opening, ending, and gaps against playback. If no captions exist, use an authorized audio transcription route and verify uncertain words against the video. Never replace missing source with a guessed lecture. Report incomplete access precisely.
4. Derive a chronological outline from the transcript, then seek to visual milestones. Capture the introductory concept board before the first question; each question's readable stimulus, stem, and all answer choices; and important intermediate/final board states showing the reasoning. Multiple frames are appropriate if the whole question cannot fit. Capture visuals where they explain a teaching step, not on an arbitrary every-N-seconds schedule. Verify the settled player timestamp and image readability after every seek.
5. Checkpoint `progress.json` after each completed segment/question: selected URL, duration, transcript status, verified through-time, completed question IDs, next seek time, missing captures, and blockers. Resume from this checkpoint instead of extracting everything again.
6. Create the adapted script in short, readable paragraphs. Keep nearly all substantive wording, examples, distinctions, wrong-answer reasoning, transitions, and teaching sequence. Remove student names, attendance, greetings, technical interruptions, repetition caused by interruption, and logistics. Replace name-based references with a natural direct explanation. Preserve specific question reasoning when it teaches something useful; do not collapse it into a generic concept summary. Mark uncertain words and missing material explicitly. Keep the untouched source transcript separate.
7. Map each script segment to its source time interval and transcript line interval, concept tags, question ID where applicable, and exact screenshot filenames/times. Put unspoken visual cues outside spoken text. The user should be able to read a paragraph, show the adjacent board, and continue without reconstructing the lesson. Include pause/check-for-understanding cues when supported by the source.
8. Use [the manifest contract](references/manifest.md) and `scripts/package_lecture.py` to generate `teleprompter.md`, self-contained `teleprompter.html`, `timeline.json`, `coverage.md`, `PROVENANCE.md`, and `SHA256SUMS`. The helper packages local captures only. It does not obtain captions or screenshots, judge logical correctness, or certify completeness. Preserve initial `transcript.md` and source screenshots unchanged; a later correction needs explicit provenance, not silent overwriting.
9. Review coverage against the entire source: all key teaching points, concept-board explanation, every worked question and substantive answer elimination, and conclusion. Record removed chatter and unresolved gaps. Check screenshot legibility and the script/image/time mapping. Open the HTML and test navigation, start/pause, speed, manual reading, and keyboard controls. Record actual checks; a successful helper run alone is not content verification.
10. Register the lecture/topic and concept tags in the owning lecture index, then append the meaningful system change to `wiki/log.md` following local routing. Report paths, source/caption confidence, questions and boards captured, and gaps. Never say complete when material or verification is missing. Do not send, post, or assign from this skill.

## Read-aloud deliverable

Keep the reading surface large and uncluttered, with navigation by concept/question, each screenshot beside the corresponding script, and timestamp cues visually distinct from speech. Autoscroll is optional and initially paused; respect reduced-motion preferences. The untouched transcript is evidence, the teleprompter is the cleaned reading copy, and coverage is the reconciliation between them.
