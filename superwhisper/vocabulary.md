# Vocabulary

Hints sent to the voice model with every recording. **Keep this short.** On 2026-09-11 the list went to 654 (every replacement target auto-added) and transcription got noticeably worse within the hour, so the auto-union rule is gone: `sync.py` sends exactly the terms below. Replacement targets are NOT added automatically any more. Superwhisper's docs are right on this one: only names and terms the voice model cannot know.
