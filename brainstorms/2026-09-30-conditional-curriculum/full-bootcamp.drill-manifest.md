## Typed task/render contract

- build-rule: blank learner-selected phrase sides with AND/OR/NOT composition; semantic equivalence rather than operand-order string equality.
- case: learner assigns truth values to labeled facts to satisfy/refute a claim; validate actual premise and target formulas.
- chain: choose ordered supplied rule edges and any required actual fact; validate each join and target entailment, not matching arrows alone.
- argument: premises, optional ADDED assumption and factual/conditional conclusion remain separate; never include the conclusion as a premise.
- quantity: explicit finite population for exhaustive model exercises; reviewed mathematical proof templates for unbounded theorem exercises. No bounded-search success presented as universal proof.
- choice: actual semantic formulas attached to options; specific hints for each selected error, exactly one justified answer unless multi-select is explicitly authored.

Atom IDs carry full subject/domain/restriction metadata; short learner-visible phrases retain meaning. Formula supports Atom/Not/And/Or recursively. Rule=if/then. Iff is two implications; inclusion=at-least-one, exclusion=not-both, exactly-one=both constraints. Inconsistent premise sets are rejected by authoring checks rather than vacuously grading everything correct. Actual item data and distractors must pass the corresponding validator.

One active operation, source rule visible, top segmented progress+percentage, bottom Previous question/Next question only. First miss gives a useful selected-error hint, preserve it through editing, model only after explicit reveal. Correct feedback explains the actual reasoning. Reveal can resolve an item without becoming independent correctness. Initial fields blank; legitimate unfinished answers resume; edit invalidates dependent validation. No self-rating completion gate.
