# Group 2: Find what's required

Group 2 introduces the necessary idea. That complete idea goes on the right.

Our Group 2 indicators are:

**only · only if · only when · only where · always · requires · must**

Use the same question: **“What is the indicator referring to?”**

### Start with “only if”

> A student enters the archive only if the student has a pass.

Only if what? Only if the student has a pass.

The pass is required:

**Enters the archive → Has a pass**

Compare that with “if”:

| Sentence | Rule |
|---|---|
| A student enters if the student has a pass. | Has a pass → Enters |
| A student enters only if the student has a pass. | Enters → Has a pass |

The first makes a pass enough. The second makes a pass required. One word changes what the sentence guarantees.

### Required things can appear first

> A pass is required for entry.

What is required? A pass.

**Enters → Has a pass**

The necessary idea appears before “required.” That's why we ask what the indicator refers to instead of automatically taking the words after it.

### Compare “only” and “the only”

> Only members are admitted.

Only what? Only members. Being a member is required for admission.

**Admitted → Member**

> The only people admitted are members.

The only what? The only people admitted. That is the sufficient idea.

**Admitted → Member**

These two sentences express the same rule. The indicator points to a different part of each sentence. Read the whole statement before deciding where each idea belongs.

### More ways to state a requirement

| Sentence | Required idea | Translation |
|---|---|---|
| A finalist must attend the interview. | Is required to attend the interview. | Finalist → Required to attend interview |
| Approval requires a signature. | Has a signature. | Approved → Has signature |
| A review occurs only when a complaint is filed. | A complaint is filed. | Review occurs → Complaint filed |
| The service operates only where a station is available. | A station is available. | Service operates → Station available |
| A finalist always receives an invitation. | Receives an invitation. | Finalist → Receives invitation |

Here, “always” expresses a rule without exceptions. Read it in context; a word by itself doesn't give you the complete relationship.
