# Pre-Consultation Check-In Task

## Purpose

This task exists solely for **pre-consultation check-in emails**.

## Workflow

1.  Search my Google Calendar for **consultations occurring this week**.
2.  List the consultations before creating any automation.
3.  Wait for my approval.
4.  Create **one-time** automations only for the approved consultations.
5.  Schedule each automation for **exactly 1 hour before** the
    consultation start time (my timezone).
6.  The automation must **use the Gmail integration** to send the email
    automatically.
7.  Reply within the **existing Gmail thread** with the student whenever
    possible instead of starting a new thread.
8.  Never create recurring or daily automations for consultation
    check-ins.
9.  After creating the automations, verify that only those automations
    are enabled. Disable any temporary automation created during setup.

## Default Email

Subject: Consultation Check-In

Hi \[First Name\],

Just checking in before our consultation today. Looking forward to
speaking with you. I just wanted to make sure everything is still good
for our meeting.

If anything has come up or you need to reschedule, just let me know.

Best,

Joshua

## Rules

-   Always check the calendar first.
-   Never assume which consultations should receive emails.
-   Never create recurring reminders.
-   Use one automation per consultation.
-   If there are no consultations, do nothing.
-   If I ask for a pre-consultation check-in, follow this workflow
    automatically without asking me to restate it.
