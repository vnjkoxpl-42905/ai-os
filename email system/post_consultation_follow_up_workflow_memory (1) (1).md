# Post-Consultation Follow-Up Workflow Memory

_Last updated: 2026-07-07_

## Purpose

This file preserves the agreed workflow for Joshua's post-consultation follow-up emails for Aspiring Attorneys. It should be used as project memory so future ChatGPT sessions do not restart from scratch or rewrite the workflow inconsistently.

## Core Goal

Establish a repeatable, consistent post-consultation follow-up email workflow for all students after a consultation.

The email should use the saved post-consultation follow-up template as the base every time. The workflow should make only slight adjustments based on the transcript/Gemini notes attached to the consultation. The goal is consistency, with a small personalized touch.

## Assistant Role

When Joshua asks for a post-consultation follow-up, the assistant's role is to:

1. Use the saved post-consultation follow-up template as the default structure.
2. Always read the consultation transcript/Gemini notes first.
3. Add only 1 to 2 personalized lines based on the transcript.
4. Keep the overall email structure the same.
5. Avoid rewriting from scratch.
6. Include the required links every time.
7. Check whether a follow-up has already been sent to avoid duplicates.
8. Prepare the email for the correct send timing.

## Source of Personalization

Always use the transcript/Gemini notes as the main source for personalization.

The assistant should not rely mainly on the email thread for personalization if transcript/Gemini notes are available. The transcript is expected to include enough detail in most cases.

If the transcript has weak details, use the standard template with minimal personalization rather than asking Joshua for more context.

## Personalization Rules

Personalization should be limited to 1 to 2 lines.

Personalization should focus on:

- Goal score
- Scholarship goal
- Law school goal
- Test date
- General timeline or prep goal

Avoid focusing on diagnostic/current score unless it is clearly necessary for context.

## Required Links

Every post-consultation follow-up should include:

1. Session booking link
2. Relevant payment/package link
3. Platform signup link

Payment/package links may vary. Use the correct payment links from the project sources once Joshua attaches or updates them.

Do not invent payment links. If multiple payment links exist, use the one indicated by the transcript, project source, or Joshua's instruction.

## Timing Rule

The post-consultation follow-up should be prepared after the consultation and scheduled for the following day at:

**3:00 PM Eastern Time**

## Sending Rule

Default rule:

- If Joshua does not say anything else, the email should be sent automatically at 3:00 PM Eastern Time the day after the consultation.

Override rule:

- If Joshua says not to send, hold the email as a draft instead.

This workflow updates the earlier draft-only rule for this specific post-consultation follow-up process.


## Readiness Verification Rule

Before looking for transcripts, drafting, scheduling, or sending a post-consultation follow-up, verify that the consultation has actually happened. Do not waste time processing future events.

Only process a student if all 3 checks pass:

1. **Calendar end time has passed**
   - Use the current time in Eastern Time / America-Montreal.
   - If the event is 7:00 PM to 7:30 PM, do nothing until after 7:30 PM ET.

2. **Gemini notes/transcript exists**
   - If the call is over but no Gemini notes/transcript exists yet, do not draft the follow-up yet.

3. **No follow-up already sent**
   - Check Gmail for a prior next-steps/follow-up email before drafting or scheduling.

If check 1 fails, stop immediately. Do not search for Gemini notes or draft anything for that student yet.

## Duplicate Prevention

Before drafting/scheduling/sending, check whether a post-consultation follow-up has already been sent.

Do not send a second follow-up unless Joshua explicitly asks or a new relevant thread/context appears.

## Relationship to Pre-Consultation Reminder Workflow

The pre-consultation reminder workflow is separate but provides context.

Pre-consultation reminders are for checking in before scheduled consultations and avoiding duplicate reminders.

Post-consultation follow-ups are for moving someone from consultation to booking/onboarding after the call.

Pre-consultation reminder context already established:

- Do not double up on anyone who already has a reminder or email sent.
- Treat handled items as handled unless a new reply comes in.
- Favour was already sent.
- Yahunathan was removed/disabled.
- The relevant current-week consult names included Favour, Yahunathan, Katie Lenhardt, Rumaysa Jahanzeb, and Taylor.

## Email Style Rules

The email should remain in Joshua's voice:

- Warm
- Simple
- Direct
- Personal but not overdone
- No em dashes
- Clear next steps
- Consistent structure

The email should not sound like a new custom essay each time. It should feel like the same professional follow-up workflow, lightly personalized.

## Default Workflow Steps

1. Identify consultation events.
2. First verify that the event end time has passed. If the consultation has not happened yet, stop immediately for that student.
3. After the event has ended, check for the attached transcript/Gemini notes. If no notes exist yet, do not draft yet.
4. Read the attached transcript/Gemini notes.
5. Extract only the most useful personalization detail, focusing on goal score, scholarship/law school goal, test date, or timeline.
6. Check Gmail/thread history to confirm no follow-up was already sent.
7. Use the saved post-consultation follow-up template.
8. Add 1 to 2 personalized lines.
9. Include the session booking link, relevant payment/package link, and platform signup link.
10. Schedule the email for the following day at 3:00 PM Eastern Time.
11. If Joshua says not to send, keep it as a draft instead.
