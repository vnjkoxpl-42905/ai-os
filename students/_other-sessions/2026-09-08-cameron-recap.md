# Necessary Assumptions: Find What the Argument Cannot Lose

A necessary assumption is something the argument needs in order to survive. It does not have to prove the conclusion. It only has to be so important that, once you take it away, the reasoning collapses.

That test works only if you are attacking the argument that is actually on the page. Before you look for an assumption, make sure you can state the evidence, the conclusion, and the gap between them without changing any of the variables.

## First, preserve the argument

An argument has two basic parts:

| Part | Job |
|---|---|
| **Premises** | Give the evidence the author wants you to accept |
| **Conclusion** | State what the author believes the evidence proves |

Grant the premises. Do not argue that the evidence might be false. Ask a narrower question:

> If every premise is true, could the conclusion still be false?

If the answer is yes, the argument is invalid. The possible exception reveals the gap in the reasoning.

The evidence does not need to make the conclusion sound reasonable. It must guarantee it. Your job is to identify what the author added, assumed, or failed to rule out.

It is possible to make a strong objection to the wrong argument. That happens when the version in your head changes a term, drops a comparison, or adds a fact that the stimulus never gave you.

Use this reading process:

1. Read one sentence.
2. Look away and state that sentence in plain language.
3. Identify what role it plays: evidence, conclusion, background, or another viewpoint.
4. After the final sentence, remove the stimulus and restate the whole argument.
5. Check that every person, group, time period, and measurement in your version matches the text.

Reading means building an accurate model of the relationships among the ideas.

### Treat changes in language as warning signs

Suppose the evidence says Maya has worked as a paramedic for ten years. The author concludes that Maya will be an excellent emergency-room nurse.

Paramedic experience is relevant, but **experienced paramedic** and **excellent nurse** are not the same idea. The argument assumes that Maya's paramedic experience gives her skills that matter to excellent emergency-room nursing.

Do not supply the connection for the author. Mark the change and ask what would need to be true for the new language to follow.

## Necessary and sufficient assumptions do different jobs

| Assumption type | Test | What it does |
|---|---|---|
| **Necessary** | Take it away | The argument collapses without it |
| **Sufficient** | Add it | The conclusion becomes guaranteed |

Think of a necessary assumption as a supporting block. Removing that block makes the structure fall. The block does not have to hold up the entire structure by itself.

A sufficient assumption is stronger. Once added, it completes the support and guarantees the conclusion.

For a Necessary Assumption question, do not ask whether an answer proves the conclusion. Ask whether the author can afford to lose it.

### Nine questions for testing necessity

These are nine different questions you can ask. They are not a nine-step process. Use the wording that makes the dependency easiest to see:

1. If the conclusion is true, does this have to be true?
2. Does the author have to believe this?
3. Does the author have to think this is true?
4. If the conclusion is proven, does this have to be true?
5. If the premises worked to prove the conclusion, is this required?
6. If these premises proved this conclusion, what must the author assume?
7. Does the argument rely on this?
8. For the argument to make any sense, does this have to be its foundation?
9. What must the author believe to think they actually proved this conclusion?

For questions 1 and 4, treat the conclusion as proven by these premises. The conclusion could happen to be true for an unrelated reason.

## Necessary assumptions can link or defend

There are two broad ways an argument can need help.

### A linking assumption connects a gap

A linking assumption supplies a connection between the evidence and something new in the conclusion.

```text
Premise: Cameron wants to attend a good law school.
Conclusion: Cameron wants to attend Michigan Law.
```

The conclusion introduces **Michigan Law**, which the premise never mentioned. The argument needs a bridge:

```text
Michigan Law is a good law school.
```

Whenever the conclusion introduces a new person, category, standard, or relationship, look for an answer that connects that new idea to the evidence.

This is a strong prediction, not permission to stop thinking. The answer must still be required by the exact argument.

### A defender assumption rules out an objection

A defender assumption protects the argument from an alternative explanation or a fact that would break its reasoning.

```text
Evidence: A preserved sample contains less of a chemical than a modern sample.
Conclusion: The chemical must be more common in the environment today.
```

The argument assumes the preservation process did not remove the chemical from the older sample. If preservation did remove it, the comparison would no longer show that the environment changed.

The required assumption may therefore be phrased negatively:

```text
The preservation process did not substantially reduce the chemical in the older sample.
```

Causal and comparative arguments often need this kind of protection because another cause or an unfair comparison can explain the result. New language in the conclusion usually points toward a linking assumption. A proposed cause or comparison usually points toward a defender assumption. These are useful predictions, not guarantees.

## Use the negation test as a collapse test

To test a possible necessary assumption:

1. Negate the answer choice.
2. Add that negation to the argument.
3. Ask whether the conclusion can still be supported.

If the negation destroys the reasoning, the original answer was necessary. If the argument can survive, the answer was not required.

### Negative wording can make the test easier

If an answer already contains **not** or **cannot**, test it early. Its negation may be as simple as removing the negative word.

```text
Answer: Preservation did not reduce the chemical.
Negation: Preservation did reduce the chemical.
```

The negated version makes the older sample unreliable. The comparison collapses, so the original statement is necessary.

This shortcut is useful, but the wording is not proof. Some negative answers are irrelevant, and some sentences require more than mechanically deleting one word. Negate the meaning of the entire claim.

## A comparison needs information about both sides

A fact about one group matters only if it changes the comparison.

Suppose older birds were not fully grown when their feathers were tested. That might sound important because a chemical accumulates as feathers grow. But the fact is inconclusive unless you know something about the modern birds too.

- If both groups were equally mature, the age issue may cancel out.
- If only one group was less mature, it may distort the comparison.
- Without the second side, you cannot tell whether the fact helps or hurts.

Use this check whenever an answer discusses only one group:

> What do I know about the other group, and does this answer create a meaningful difference between them?

“Could matter” is not enough. A necessary assumption must be something the argument requires.

## A repeatable approach

1. Restate the premises and conclusion without changing any of the variables.
2. Ask whether the premises guarantee the conclusion.
3. Name one way the premises could be true while the conclusion is false.
4. Decide whether the argument needs a link or protection from an objection.
5. Use the necessity question that makes the dependency easiest to see.
6. Negate the answer. Choose it only if the argument collapses.
