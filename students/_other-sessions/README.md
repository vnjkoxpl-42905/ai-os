# Other sessions — reference corpus

Gemini session notes for people who do **not** have a student folder in `students/`.
Consultations that never converted, one-off sessions, group sessions, and prospects.

This is a **reference corpus, not a student ledger.** Nobody here has a profile,
open loops, assignment log, or live status. Do not treat a file here as evidence
of an active student relationship, and do not draft correspondence off it without
checking whether the person is current.

## What it is for

Raw teaching material, kept flat so it can be read and analyzed in bulk:

- analyzing how Joshua teaches, explains, and runs a session
- extracting LSAT content, worked explanations, and question breakdowns
- formulating session scripts and consultation scripts from what actually worked
- giving the second brain more grounded knowledge of the domain and of Joshua

## Layout

One file per session, flat:

```
YYYY-MM-DD-<person-slug>-notes-by-gemini.md
```

Same convention as `students/<name>/transcript-downloads/`, so both sets grep and
sort together. Multiple docs for the same person and date get a `-2`, `-3` suffix.

## Provenance

Exported from Google Drive with `gws drive files export` (prefer `text/plain` for new
exports; older files used `text/markdown`), sourced
from Gemini notes attachments on Google Calendar events. Google Drive is upstream
authority; these are mirrors. Files are unedited exports — treat them as source
evidence and do not hand-edit. To refresh or extend, re-run the export against the
Calendar sweep rather than patching files here.

Some calendar events reference Gemini docs that no longer exist in Drive; those
sessions have no file here and cannot be recovered.

An attached Doc can be a consultation rather than a student session. Keep it here
until a taught student relationship is verified. If a source records an objection
to transcription, do not distill or repurpose it; resolve retention with Joshua.
The 2026-09-11 Venusa source was deleted on 2026-09-28 at Joshua's instruction,
honoring her objection to transcription: the Google Doc, its Meet folder, the
Drive backup copies, and every local copy. Do not recreate it.
