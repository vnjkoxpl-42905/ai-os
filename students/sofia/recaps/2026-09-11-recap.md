# Conditional Must Be True

A conditional Must Be True question usually gives you one of two situations:

1. **Rules only:** connect the rules by finding a bridge.
2. **Rules and facts:** apply the facts to the rules.

Start by identifying which situation you have. Then make only the inference the stimulus supports.

## First, separate facts from rules

### A fact tells you what is true

A fact gives you information about a person, group, object, or situation.

```text
Fact: Lena is a pilot.
```

### A rule tells you what follows

A rule gives you a conditional relationship. It has a trigger and a result.

```text
Rule: pilot → licensed
```

The rule does not prove that anyone is a pilot. It tells you what must be true **if** someone is a pilot.

## Scenario 1: Find a bridge

Use this method when the stimulus gives you multiple rules but no fact that activates them.

### Step 1: Diagram each rule

```text
A → B
B → C
```

### Step 2: Find the repeated idea

`B` is the bridge. It is the result of the first rule and the trigger of the second rule.

### Step 3: Connect the loose ends

```text
A → C
```

The repeated term must be in the correct position. Two rules do not form a chain merely because they mention the same idea.

## Scenario 2: Apply facts to rules

Use this method when the stimulus gives you a rule and a fact about a particular case. Compare the fact with the trigger and the required result.

### Apply the rule forward

```text
Rule: pilot → licensed
Fact: Lena is a pilot.

Conclusion: Lena is licensed.
```

The fact matches the trigger, so the rule gives you the result.

### Apply the contrapositive

```text
Rule: pilot → licensed
Fact: Lena is not licensed.

Conclusion: Lena is not a pilot.
```

The fact denies the required result. Reverse the rule and negate both sides:

```text
pilot → licensed
not licensed → not pilot
```

## Keep the direction exact

From `A → B`, only two forms are valid:

1. **Original rule:** `A → B`
2. **Contrapositive:** `not B → not A`

These forms are invalid:

1. **Reversal:** `B → A`
2. **Negation:** `not A → not B`

Knowing the result does not prove the trigger. Knowing that the trigger is absent does not prove that the result is absent.

## A quick process for every question

1. Label each statement as a **fact** or a **rule**.
2. Decide which situation you have:
   - rules only: find a bridge;
   - rules and facts: apply the facts to the rules.
3. Write the valid inference before looking for it in the answers.
4. Check that the answer preserves the direction of every rule.
