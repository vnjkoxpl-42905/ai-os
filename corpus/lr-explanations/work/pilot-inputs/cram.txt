***ASSUMPTION / OBJECTION FAMILY***
IDing Assumptions: Conc has a new idea the Evid didn’t
IDing Objections: Given the Evid is true, how could I stillargue the Conc is wrong? (how can I argue the Anti-Conc?)
Explain Curious Fact: (common on Str / Wkn / Flaw / NA)Evidence describes a curious comparison, often a CorrelationConclusion proposes a Causal Explanation- Think: Are there any Alternate Explanations?Reverse Causality? Both Effects of the same Cause?
- How Plausible is the Author's Explanation?Cause w/o Eff? Eff w/o Cause? No Cause, No Eff (control group)?
Flaw (Very Predictable. 40% test a Famous Flaw)If no Famous Flaw, ID an Assumption or an Objection- 3 types of answers: Assumption, Objection, DescriptionASSUMPTION: takes for granted, presumes, fails to establish- beware: strong/broad, use negation test (see below) if unsure
OBJECTION: fails to consider, neglects/overlooks possibility- if the overlooked thing was true, would it weaken the argument?
DESCRIPTION: everything else- Did the arg really do this? If so, is that really a problem?- Infers from (evid) that (conc); Treats (evid) as though (conc)
Necessary Assumption (Less Predictable, esp Q15-26)½ test a Missing Link Assumption, ½ Rule Out an Objection- Don’t see a Missing Link? Use Anti-Conclusion to ID an Obj.- BEWARE strong/broad; EMBRACE weak, ruling-out, “not”- NEGATION TEST: which answer, if negated, most weakens
Sufficient Assumption (answer + evid
→ conclusion)- “New Idea” in Conc connected to 1-mention Ev Idea- Correct answer often contrapositive (CP) of prediction- Wrong answers: right ideas, wrong order; lack new idea
Principle-Strengthen (Very Predictable, Missing Link)- “If [facts from Evid], then [Judgment from Conc]” or CP.- Wrong Answers: different judgment, connect the judgmentto unknowns/opposites instead of the Evid facts, assign thejudgment to the wrong party (cops should vs juries should)or go in the wrong order (If judgment, then facts)
Strengthen / Weaken / Evaluate (Less Predictable)- mainly Explain Curious Fact, Plans/Recommendations, orarguments by Comparison/Analogy.STR: Support Plausibility, Neutralize Objections, Add HelpWKN: Attack Plausibility/Assumptions, Raise ObjectionsEVAL: which question has the power to Str or Wkn?
***MATCH FAMILY***
Parallel / Parallel Flaw (Predictable Structure, not Content)- If there are Conditional or Quantified claims, Diagram- If not, try to describe the logic abstractly (e.g. “rules outone explanation in order to prove another”)- Par Flaw: Name Flaw 1st! often Nec vs. Suff / Part vs. Whole- Correct: often scrambles order. Trap: similar topic / words
Main Conclusion (Very Predictable)- 90% of them: First line or Pivot/Rebuttal (but/yet/however)- Traps: Last Claim, Intermediate Conclusion, Inference
Role (Predict: Main Conc, Supports, Opposes, Neutral)- Like Main Conc, mostly “upside down args” (Conc above Ev)- Intermediate conclusions give support and have support.
Method (common moves: analogies/distinctions, faultyimplications, or eliminating/suggesting alternatives)
Principle-Conform (Predictable Structure, not Content)Principle/s in the Stimulus: match like a Parallel Q.Principle in Answers: play like Principle Strengthen Q.
***INFERENCE FAMILY***
Must Be True / Most Supported (Very Predictable)- Find 2+ claims that can be combined. Look for OverlappingConcepts, conditional/causal wording, or pivots creatingtension. MBT favors Conditional and Mathy stuff. MSSfavors Causality and Comparisons.- BEWARE new ideas, EMBRACE weak/familiar ideas
Must Be False (rare, Predictable Structure)Answer contradicts a provided conditional or an inference
Agree / Disagree (Very Predictable)- Read both, then TAKE PERSON 1’s CLAIMS one at a time:“did person 2 (dis)agree with this claim or not address it?”- If you can’t find explicit overlap, consider assumptions.- BEWARE weak answer language. It’s hard to disagree with!
Paradox (Less Predictable, esp Q15-26)GIVEN the background fact(s), HOW CAN WE EXPLAIN thesurprising claim?- Usually Comparative: right answer is a helpful Difference- Traps contradict background facts or deepen the paradox.- BEWARE weak answers. EMBRACE strong/new ideas.
