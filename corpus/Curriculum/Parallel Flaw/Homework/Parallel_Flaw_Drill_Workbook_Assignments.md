**Parallel & Parallel‑Flaw Drill Workbook**

Logical Reasoning --- Organized practice sets with clear, concise
instructions. Use only the LSAC questions listed by Practice Test,
Section, and Question numbers.

**How to use this workbook**

For each stimulus:

• Identify each claim's ROLE (Premise / Background / Conclusion).

• Assign exactly ONE Claim Type: Conditional / Either‑or / Normative /
Quantified / Comparative / Causal relationship / Statement of fact.

• Assign exactly ONE Modal Strength: Certain / Probable / Possible.

• Circle/underline the KEYWORDS that reveal the type (e.g., "only if,"
"if...then," "tend not to," "more than," "many," "should," "might,"
"result of," "either...or").

• If conditional, DIAGRAM it (e.g., X → (Y ∨ Z); use 'only if' as a
necessary condition).

• PREPHRASE the expected parallel pattern in one short line (e.g.,
"denies sufficiency from exceptions," "correlation ≠ causation via
common cause," etc.).

• After selecting an answer, catalog the flaw for ALL five choices (even
if you answered correctly).

**Stage 1 --- Structure & Diagram (untimed, analysis‑first)**

• Read the stimulus. Before looking at choices, complete the analysis
table.

• Mark ROLE, pick ONE Claim Type, pick ONE Modal Strength, and underline
the keywords.

• If conditional language appears, diagram it cleanly.

• Write a one‑line prephrase of the target pattern.

cite the keywords that signal it.
