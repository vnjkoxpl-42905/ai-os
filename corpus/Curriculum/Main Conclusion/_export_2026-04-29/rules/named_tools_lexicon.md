# Named Tools Lexicon

The 15 named pedagogical tools that appear in the Main Conclusion app. All preserved verbatim per the voice/content directive. Most extend across other LSAT U topics; new ones may be added per topic.

## Carried from Joshua's existing corpus (preserve as platform-wide vocabulary)

### FABS
**What:** Premise / support indicator quartet — For, After all, Because, Since.
**Where it lives:** Reference §2.C, Lesson 1.3, Lesson 1.10.
**Source:** main_conclusion_role_merged_note.pdf (S), Indicator word list.pdf (A).

### 2-Part Conclusion Check
**What:** Verification protocol. (1) Sounds like author's opinion? (2) Supported by at least one explicit claim?
**Where it lives:** Reference §2.B, Lesson 1.11, Quick Reference Card §2.J.
**Source:** Main conclusion (recap).pdf (S), Synopsis.pdf (S).

### Upside Down Argument
**What:** Framing for the LSAT pattern of putting the conclusion before its support (vs school's "conclusion goes last" rule).
**Where it lives:** Lesson 1.4.
**Source:** Main Conclusion Synopsis.pdf (S).

### Trojan Horse Concession
**What:** Naming for concessions — they look like agreement but are setting up the rebuttal.
**Where it lives:** Lesson 1.8, Reference §2.I.
**Source:** argumentslr prototype's framing terminology, applied to Joshua's concession content.

### Pre-Phrase Goal
**What:** The pronoun-replacement protocol. Replace "such laws" / "this position" / "they" with the actual reference language before stating the conclusion.
**Where it lives:** Lesson 1.10, Reference §2.H, Drill 3.7.
**Source:** Main Conclusion Synopsis.pdf (S).

### Skeptic's Ear Check
**What:** R&R Drill prompt — "What's the simplest question or challenge to this statement?" asked after rephrasing each piece.
**Where it lives:** Drill 3.8.
**Source:** R&R Drill Stage 2 Instructions.pdf (S).

### Stegosaurus Interrogation
**What:** Diagnostic technique for telling premises, conclusions, and intermediate conclusions apart by asking "How do I know that?"
**Where it lives:** Lesson 1.7, Drill 3.5.
**Source:** Hybrid argument notes.docx (S).

### Indicator Vault
**What:** The 6-category color-coded lookup for indicator words.
**Where it lives:** Reference §2.A, MC Companion app.
**Source:** Naming new for the new build (lifted from MC Companion's "Indicator Vault" UI label).

### Coach's Note
**What:** Per-question explanation card. Structure map + core move + per-answer audit.
**Where it lives:** Module 4 §4.5.
**Source:** Masterclass workbooks (S, format kept verbatim) + argumentslr's "Coach's Note" framing.

### R&R Drill (Read & Restate)
**What:** Methodology — read piece, cover, rephrase from memory, Skeptic's Ear Check, cumulative recall, full recollection.
**Where it lives:** Drill 3.8.
**Source:** R&R Drill Stage 2 Instructions.pdf (S).

## New names introduced for the build (carry forward to other topics)

### X-Ray Scan
**What:** Toggle reveal of role colors over a quote/stimulus block. Premise/conclusion/opposing/indicator highlighted.
**Where it lives:** Drill 3.2, Lessons 1.1-1.8 quote blocks, Module 4 Coach's Note overlays.
**Source:** logicalreasoningfoundation.netlify.app prototype (S codebase).

### Trap Master
**What:** The 7-trait diagnostic system. Every wrong answer in the Simulator is tagged with one of the 7 traits.
**Where it lives:** Module 4 §4.3, Diagnostic dashboard §6.3.
**Source:** Built on Advanced- MP Question Traps.docx (A) + masterclass workbook deep dives (S).

### Stage-Gate Tracker
**What:** Universal drill wrapper. 4 stages × 5 questions, score 4/5 to unlock next, auto-save, PDF export.
**Where it lives:** Drill 3.4 (and applied to all Module 3 drills as the universal frame).
**Source:** mainconclusionrebuttalvsfirst.netlify.app (S codebase, lifted verbatim).

### Pronoun & Reference Library
**What:** The list of words to scan for in candidate conclusions: this / that / they / such / these / those / this position / such laws / etc.
**Where it lives:** Reference §2.H.
**Source:** New naming for content from Synopsis.pdf and role_merged.pdf.

### Concession Decoder
**What:** The structural reveal: Concession → Pivot → Author's claim → Support.
**Where it lives:** Reference §2.I.
**Source:** New naming for content from Argument Core & Periph.pdf and Indicator word list.pdf.

## Rule

Every named tool carries forward verbatim with its name unchanged. New named tools may be added for invented features — but the existing 15 names are part of the platform's shared vocabulary for LSAT U.
