## AI retrieval infrastructure added on 2026-10-15

The [shared AI retrieval guide](AI-RETRIEVAL.md) is now linked from both runtime root instructions and the domain landing page. The domain's AGENTS.md and CLAUDE.md are byte-identical. This establishes the same documented entry and source-handling rules for Codex and Claude; it does not claim a separate Claude model session was executed.

`system/scripts/query-loophole.py` supplies a local SQLite full-text locator over the actual captured bodies. It is built from explicit source categories, including the Git-ignored question publication, rather than depending on a global file search. It separates RC, LR, shared material, workouts, routines, notes, lectures, references and prep-map sources. Exact current citations precede old-citation aliases, and exact titles rank ahead of broad lexical matches.

The index is a generated, disposable cache. No model API, embedding upload, extra server or new knowledge authority is required. Search returns bounded JSON with source paths, source type, status, excerpts and line references. Catalog/publication guards and returned text hashes detect stale evidence; a rebuild command is explicit. Companion MP3 availability is metadata, not a new binary audit per lookup.

The AI must read the full relevant source before giving instructions, preserve source errors and ambiguity, distinguish written notes from ASR and editorial text, and cite the local artifact. A missing RC database record is not an absent RC lecture. A silent MP3, unavailable audio, invalid subtitles and failed source capture are separate states.

The [query proof](retrieval/query-proof.generated.json) and [independent lookup acceptance](retrieval/root-acceptance.generated.json) record actual retrieval tests and timings. Latency is measured on this machine, not a universal promise of instantaneous or semantically perfect retrieval. Human transcript accuracy and missing-source acquisition remain separate work.
