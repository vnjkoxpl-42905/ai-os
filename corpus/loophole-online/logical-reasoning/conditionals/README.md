## Eighteen core lessons and their conditional applications

The [lecture archive](<../../../../Loophole Lecture/Conditional Reasoning 2026-10-18/README.md>) contains the 18 core Concept Review lessons, seven explicitly related conditional applications and one directly prescribed Acronym homework walkthrough. Each lecture has its own original caption text, readable native transcript, written-note status, observed inline questions and book-excerpt availability. Per-artifact completion is established by the archive's verification records, not this navigation page. Final package verification records 26 of 26 lecture packages complete, including native media and supplements, with 78 observed final inline answers verified. This establishes captured artifacts and resolved observed UI states; it is not word-by-word listening review.

Core topics cover if/then fundamentals; basic diagramming; and/or contrapositives; chains; if and only if; inclusion/exclusion; unless; purposeful contrapositives; nested conclusions; some/most and their inferences; not all; and few. Applications include conditional versus causal reasoning, bad conditional reasoning, Conditional SA strategy/example, the Necessary Condition Trick, Conditional Parallel Flaw and Diagramming Drama. [Before-intake inventory](comparison-before.md) lists exact titles, URLs and historical gaps.

Use native captions for speech, Ellen's Notes for captured authored wording, and each lecture's `inline-bootcamp.md` for the complete observed question sequence and feedback. These in-video questions are a distinct source from Book Extras Bootcamps. Their alternative response branches are preserved only where observed.
