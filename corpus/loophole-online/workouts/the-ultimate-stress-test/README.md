### Instructions

**NOTE**: Do not attempt The Ultimate Stress Test if you have not beaten MemAC or if you have never done a Write In.

1. Write In the odd questions in the section* .

2. MemAC the even questions in the section.

3. Return to the Write-In questions:

   1. MemAC the answer choices.

   2. Choose an answer using only your Write In without looking back at the stimulus.
4. Return to the even MemAC questions:

   1. Attempt to Write In the correct answer from what you remember of the MemAC.

### Ellen's Advice

#### If You Want to Win

- The Ultimate Stress Test is not for the faint of heart and is an **entirely optional** workout.

  - Very few people at Elemental do the Ultimate Stress Test, but it can be helpful to a small minority of students who want to push themselves before their exam.
- Do all the questions in order.

  - This means you'll be alternating between MemAC and Write Ins throughout the section.
- In order to do the Ultimate Stress Test, you must be familiar with the Write In and MemAC instructions.

  - Reference the Write In and MemAC workout instructions, if needed, before completing this workout.

## You're Not Hoping it Will Be Easy

Hoping the test will be easy sets you up for outrage, disappointment, and chaos actions that decrease the score. The truth is the test will be hard. That's a feature, not a bug. But we do hard things. Your process is build for the most difficult questions.
