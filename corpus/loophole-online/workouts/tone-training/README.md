#### Will This Help Me?

This will help you if

You struggle with RC Tone questions and can't feel the author's attitude.

Skip for now if

You already intuitively can pick up on tone and attitude in a piece of text.

challenge index Pretty Chill

level Beginner

minimum time 40+ minutes

timing compatible with Stopwatch

### Instructions

1. Highlight the adjectives and adverbs in a few passages*  to train yourself to notice them.

2. At the end of each passage, ask yourself, "How did this passage feel?" and use the adjectives and adverbs to help you.

3. Write down your answer to how this passage feels before doing the questions.
