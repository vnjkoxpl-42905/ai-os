Instructions

Open up a previously-seen LR or RC section*.

Translate the first four questions' answer choices in the style of a Written Answer Choice Translation Spreadsheet.

Read only the answer choices for these four questions.

Do not read the stimulus or the question stem.

Write down each individual answer choice.

Write down a Translation of each answer choice.

This means read A, write the literal text of A, and write the Translation of A. Then repeat the same process on B, C, D, and E.

Use the same spreadsheet and same style as you used when you completed the Answer Choice Translation Primer.

Translate the next four questions' answer choices in the style of an Out Loud Answer Choice Translation Drill.

Read only the answer choices in the section.

Do not read the stimulus.

Do not read the question stem.

Translate the answer choice out loud.

Quip the answer choice out loud.

This means read A, translate A, and quip A. Then repeat the same process on B, C, D, and E.
