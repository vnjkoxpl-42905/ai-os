## 🔍 Deep Dive: GPT-5.6 Luna (Your Focus)

### What Makes Luna Special?
Luna isn't trying to be the "smartest" model overall — it's built to be the **toughest critic**. Think of it as the senior engineer who reviews your pull request and finds the one edge case that would have caused a production outage.

### Luna's Superpowers 💪
1. **Adversarial Code Review** — Finds subtle logical regressions other models miss
2. **Plan Stress-Testing** — Will poke holes in your architecture before you build it
3. **Security Analysis** — Catches potential security vulnerabilities during multi-round reviews
4. **Cost Efficiency** — Among the cheapest reasoning-tier models per task (confirmed by Artificial Analysis)
5. **Codex CLI Integration** — Best-in-class for automated multi-round development workflows

### Luna's Weaknesses 🤔
1. **Verbosity** — Can over-explain and be hyper-critical on simple tasks
2. **Not the Best Writer** — Prose tends toward corporate/mechanical compared to Claude
3. **Needs Prompt Calibration** — For quick everyday tasks, you may need to tell it to keep it simple
4. **Not Great at Multimodal** — Can't match Gemini for video/audio/massive document ingestion

### When to Use Luna vs. the Others

| Scenario | Best Choice | Why |
|---|---|---|
| "Review my code for bugs" | **Luna** 🟢 | Built for adversarial critique |
| "Refactor this entire codebase" | **Claude** 🟣 | Better at understanding architecture |
| "Analyze this video + these docs" | **Gemini** 🔵 | 1M multimodal context is unmatched |
| "Write me a blog post" | **Claude** 🟣 | Most natural, human-sounding prose |
| "Is my system design secure?" | **Luna** 🟢 | Will stress-test every assumption |
| "Build me an AI agent" | **Gemini** 🔵 | Custom tools endpoint is best for this |
| "Solve this hard math problem" | **Claude** 🟣 | Adaptive Thinking goes deepest |
| "Quick daily tasks, voice chat" | Any / **Gemini** 🔵 | Fastest with Google ecosystem integration |
