A Applications
The front pages of your OS. These are not app-store apps: they are sm all tools and at-a-glance pages
your AI writes as files you can reopen any tim e. A tracker, a num bers page, a calendar view. If you
check it or update it weekly, it deserves a page.
E-COMMERCE STORE
One page showing this week's orders,
refunds, and top products.
AGENCY / SERVICES
A client onboarding tracker: who is at
which step, what is waiting on you.
SAAS BUSINESS
A trial pipeline page: signups this
week, who activated, who went quiet.
S E T  IT  U P
1. List the 3 to 5 things you check or update every week, and how you do each today.
2. Pick one. Have your AI build it as a single self-contained file you can reopen.
3. Keep every app in one folder, for example OS/apps.
4. Have your AI build a home page that links to every app in the folder.
5. Open the home page each morning. What you never open, delete.
COPY-PASTE PROMPT
I'm setting up the Applications part of my agentic operating system: small tools and at-a-glance pages you build
for me as files I can reopen any time.
Before you build anything, ask me these questions in one batch and wait for my answers:
1. What do I check or update every week, and how do I do it today?
2. Where does that information live right now (spreadsheets, apps, notes)?
3. What would I want on a single home page if I opened it every morning?
Then build the one tool I pick first as a single self-contained file, plus a home page that links to it. Keep everything
in one folder called OS/apps, and tell me exactly where each file is saved.
You're done when: you open one home page and every tool you use weekly is one click away.

1. What work do I repeat every day, week, or month?
2. For the one we pick: what goes in, what should come out, and where should the result go?
3. What time and day should it run, and in what timezone?
Then write the routine as a clear, repeatable instruction and show it to me so I can check it. If you have a
scheduling feature, schedule it. If not, save the instruction so I can run it with one line each morning.
You're done when: one piece of work shows up on time without anyone asking for it.

M Memory
W hat your AI knows about you before you type a word. By default, m ost assistants rem em ber little or
nothing between conversations, so you re-explain your business every tim e. The fix is one folder of
plain-text notes your AI reads at the start and adds to when som ething worth keeping happens.
DECISIONS
"Onboarding is priced at $2,500 flat.
Decided March, not up for debate."
PREFERENCES
"Drafts in short sentences, no jargon.
Never schedule sends on Fridays."
CURRENT STATE
"Spring launch is the priority until
April 30. The rebrand is parked."
S E T  IT  U P
1. Create a folder called OS/memory. One note per fact, so single facts stay easy to update.
2. Create an index note called MEMORY that lists every note in one line each.
3. Save your first five facts: your business, how you like work done, what's in flight, what's decided.
4. Tell your AI to read the index at the start of every conversation.
5. New rule: when a decision, preference, or correction comes up, it gets saved in the same conversation.
COPY-PASTE PROMPT
I'm setting up the Memory part of my agentic operating system: a folder of notes you read at the start of every
conversation so I never have to re-explain myself.
Before you create anything, ask me these questions in one batch and wait for my answers:
1. What should you always know about me and my business?
2. How do I like work delivered (tone, format, length)?
3. What am I working on right now, and what decisions are already locked?
Then create a folder called OS/memory with one note per fact, plus an index note called MEMORY that lists every
note in one line. From now on, when I state a decision, preference, or correction, save it as a note and update the
index in the same conversation.
You're done when: a brand-new conversation answers "what am I working on right now?" correctly, with zero
re-explaining.

S Skills
Saved, nam ed procedures your AI follows the sam e way every tim e. A skill is a set of instructions you
write once - the steps, the standards, an exam ple of great output - so the tenth run is as good as the
best run, and you stop re-teaching the sam e task in chat.
CONSUMER BRAND
"Product drop post": announcement
copy in your voice, three platform
versions.
AGENCY / SERVICES
"Call to follow-up": turns a meeting
transcript into a client-ready email.
E-COMMERCE STORE
"Description batch": product
descriptions in your store's exact
format.
S E T  IT  U P
1. Notice what you've asked for 3 or more times. That's your first skill.
2. Write it as one file: a name, when to use it, the steps, and one example of good output.
3. Save it in a folder called OS/skills.
4. Run it by name: "run the follow-up skill on today's call".
5. When a result misses, fix the file, not the chat. That's how the fix sticks.
COPY-PASTE PROMPT
I'm setting up the Skills part of my agentic operating system: saved step-by-step instructions you follow the same
way every time I name them.
Before you write anything, ask me these questions in one batch and wait for my answers:
1. What have I asked you to do three or more times?
2. For the one we pick: what separates a great result from an average one?
3. What past examples of good output can I give you to copy the style from?
Then write the skill as one file in a folder called OS/skills, with a name, when to use it, the steps, and one example
of good output. When a result misses, I'll tell you what was off, and you update the file so the fix sticks.
You're done when: one line ("run the newsletter skill") gets you a full deliverable, the same way every time.

PUTTING IT TOGETHER
The 7-daysetupplan
Y ou read ARM S front to back. Y ou build it memory-first, because every other part w orks better wh en your
AI already know s your business. One part a day, sm all on purpose: a system  you actually finish beats a
bigger one you abandon.
Day 1 M em ory. Run the Memory prompt (page 5). Save your first five facts and the index.
Day 2 Skills. Run the Skills prompt (page 6) on the thing you ask for most often.
Day 3 Routines. Run the Routines prompt (page 4). If your Day 2 skill repeats weekly, schedule it.
Day 4 Applications. Run the Applications prompt (page 3). Build tool number one.
Day 5 Hom e page. Have your AI link every part - apps, skills, memory - from one page.
Day 6 Test day. Run everything once. Fix misses by editing the files, not by re-explaining in chat.
Day 7 Add one. A second skill, routine, or app - whichever gap you felt most this week.
KEEP IT ALIVE
Fifteen minutes, once a week: prune memory notes that went stale, tighten one skill file, and check that your
routine outputs actually landed. The system compounds only while the files stay true. Stale memory is worse
than no memory, because your AI acts on it with confidence.
