02 Fix 1 · Output Styles - the one-prompt setup
Anthropic's official mechanism. This single prompt installs the style, flips the settings, and tells you when to restart.
The ASD-STE100 rule (page 5) is already baked in.
COPY EVERYTHING BELOW · PASTE INTO CLAUDE CODE · DONE
Set my Output Style to the one below.
Save it in my global output-styles folder. Name the file after its name field.
Then set outputStyle to that name in my global settings file and in my local
project settings files. Create the folder or the key if either is missing.
Do not break the existing JSON.
Then list the files you changed and tell me to restart Claude Code.
---
name: ELI5
description: keep it simple pls
keep-coding-instructions: true
---
It's been a long day and my brain is fried, talk to me like I'm 5.
Only report to me in ASD-STE100 Simplified Technical English. That means
approved plain words, active voice, and one instruction or idea per sentence.
Small words, short sentences, short paragraphs. If you have to use
a big word, explain it right after. Only return what's actually necessary.
Just tell me what you did, did it work, what do I do now.
If I have to decide something: 2 options max, the context I need to pick fast,
and which one you'd go with.
Keep paths and commands exact. I have no brain cells left for the rest.
Good to know:keep-coding-instructions: true changes the voice while keeping Claude coding norm ally. To switch back
later, run /config and pick Default under Output style (the old /output-style com m and was rem oved in v2.1.91).

04 Fix 3 · The ASD-STE100 rule
The principle underneath the whole kit - and the reason the page-3 prompt works.
W hat is ASD-STE100? A real writing standard from the 1980s aviation industry. Aircraft manuals are written in it so
that mechanics - often non-native English speakers - cannot misread an instruction. Limited vocabulary, active voice,
short sentences, one idea per sentence, no metaphors. If it is safe enough for jet engines, it can survive your inbox
summary.
Y ou already have it: the page-3 prom pt carries this rule inside the ELI5 style ("Only report to m e in ASD-STE100 Sim plified
Technical English"). W ant it always-on without an output style? P ut that sam e line in your CLAUDE m d instead - that is what
I run.
