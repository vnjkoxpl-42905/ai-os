# Terms used in this review

These definitions clarify the proposal and refer to the existing app-owned context. They do not replace the application glossary or approve a product rename.

| Term | Meaning |
| --- | --- |
| Question finder | Existing shared control for locating a known question by reference or remembered text. Student trigger remains Find a question when both banks can open results. |
| Lookup | An ordinary verb for the finder's task, not a new student-facing feature name. |
| Home | Student dashboard at /classroom. Its requested finder entry is separate from the permanent rail shortcut. |
| Practice > Drills | Current owner for drill selection/history/setup. The current finder modal is hosted here when launched from the rail. |
| Preview | Inspection without creating or answering a scored attempt. RC metadata is initially visible; explicitly revealing RC text records exposure. Existing LR preview has no equivalent exposure write. |
| Target selection | Resolving a specific question or passage and requesting preview. It must not invoke cancel-to-origin navigation. |
| Dismissal | Closing lookup without selecting a target. An in-place host retains its page; a legacy URL-launched finder may return to its validated caller. |
| Exposure | A record that passage text was revealed under the existing RC policy. It is distinct from submitting an answer or creating a drill. Do not imply LR has equivalent fresh-question tracking. |
| Attempt | Work started/answered in a drill session. Finding a reference or opening metadata must not implicitly create one. |
| Set | Group of questions assembled for practice. Builder search selects questions into a set; finder search opens a reference for inspection. |
| RC-only fallback | A deliberately scoped delivery with only openable RC results and accurate labels. It must not advertise LR lookup while leaving its open action disabled. |
| Independent approval | Runner status completed and response verdict APPROVED for the exact reviewed plan. It certifies a plan review, not implementation, deployment or live acceptance. |
