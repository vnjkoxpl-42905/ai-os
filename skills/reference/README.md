# Reference skill collections

Third-party / open-source skill bundles kept here for use and study. These are **not** authored by you and are **not** part of the canonical authored-skill set in `../` — they just happen to be packaged as skills.

- **`browser-harness/`** — `browser-use/browser-harness`. A thin, editable CDP layer that connects an agent directly to your real Chrome. Ships as a skill (`SKILL.md`, name `browser`) plus `interaction-skills/` and `domain-skills/`. Use it to automate/scrape/test the browser; the agent writes helpers into `agent-workspace/` as needed.
- **`open-design/`** — `nexu-io/open-design`. Open-source alternative to Claude Design: an artifact-first design engine with 9 skills, 72 brand-grade design systems, and prompt templates. Referenced for design-engineering ideas (e.g. LSAT U UI).

Source-preserving copies; no remotes or nested `.git`. `node_modules/` omitted.
