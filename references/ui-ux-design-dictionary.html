Too Many Pieces Container-itis / Nested Border Overload Gestalt Law of Proximity
Layout & Spacing
Root Cause

Relying on explicit border lines and nested card wrappers to separate content instead of letting whitespace and subtle background tint shifts do the work.

Professional Standard

Refactoring UI: Eliminate borders on nested child containers. Use 24px to 32px of whitespace or a 1-step background contrast shift (e.g. stone-50 against white).

Copy-Paste Engineering Directive
Refactor this view to eliminate nested card borders. Remove the outer border on all child containers inside the main card. Instead of drawing box outlines around every section, group related elements using vertical whitespace (margin-bottom: 24px) or a subtle surface tint shift (bg-stone-50 with 0px border). Keep only the primary outer card boundary.
"Whenever you feel like reading is exhausting, like a tennis match tracking across the monitor..."
Hard to Read Overextended Measure / Excessive Line Length Robert Bringhurst Typographic Standard (45-75 chars)
Typography & Reading
Root Cause

Allowing reading passages or lesson copy to expand to 100% width of a wide container or full monitor width (reaching 100+ characters per line).

Professional Standard

Optimal reading length is 55 to 70 characters per line (approx. 65ch in CSS). Longer lines cause eye strain, loss of place, and cognitive fatigue.

Copy-Paste Engineering Directive
Constrain the reading column to an optimal typographic measure. Apply max-width: 65ch (max-w-[65ch] or max-w-2xl) to the lesson text and question stimulus container. Center the reading container or dock it alongside an inspector column rather than letting text span the full monitor width.

Root Cause

Root Cause

Buttons & Affordance
Root Cause

Professional Standard

Interactive elements must visibly declare interactability via cursor: pointer, hover surface transitions, subtle elevation, and action icons (like trailing chevrons).

Root Cause

Feels Clunky Feedback Latency Gap / Double-Submit Vulnerability Nielsen Heuristic #1 & Doherty Threshold (<400ms)
State & Latency
Root Cause

Awaiting an asynchronous backend response before updating the UI, with no immediate disabled state, inline spinner, or optimistic update.

Professional Standard

System feedback must occur under 400ms. On click, immediately disable the button to prevent duplicate submissions and render an active loading state.

Copy-Paste Engineering Directive
Add immediate synchronous interaction feedback to this submit action. On click, instantly disable the button to prevent duplicate submissions, swap the label for an inline spinner with 'Submitting...', and apply optimistic state updates locally where possible.

Lost / Confusing Flow Wayfinding Failure / Missing Context Anchor Steve Krug Trunk Test (Don't Make Me Think)
Navigation & Wayfinding
Root Cause

Hiding top-level navigation and breadcrumbs during multi-step flows without replacing them with a clear hierarchical progress header.

Professional Standard

At any step, a student must know: Where am I? Where did I come from? How do I get back? Provide breadcrumbs and an explicit exit hatch.

Copy-Paste Engineering Directive
Add a persistent breadcrumb trail and exit anchor at the top of the runner (e.g., 'Classroom > Main Conclusion Bootcamp > Drill 2 > Question 4 of 10'). Include a clear 'Save & Exit' button that preserves current progress and returns to the dashboard.

Navigation & Wayfinding
