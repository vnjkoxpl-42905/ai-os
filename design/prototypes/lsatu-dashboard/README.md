## Preservation and limits



All original source folders in Downloads remain untouched. Every copied source file was hashed before and after copying and compared with the destination. No source symlinks were followed. Existing provenance files are preserved verbatim; old absolute paths in historical notes remain historical paths. Use this archive's index for current local navigation.



These are local reference studies and historical signed-in screenshots, not a public website. No publishing, Git commit/push, application migration or production change was performed. Some historical images may contain account or student information; no anonymity claim is made.



Do not infer production acceptance from a local preview or screenshot. Versions 08, 09 and 10 remain sample-data prototypes, not live-data integration. Versions 08 and 09 are preserved as historical iterations; 11 Claude studio is the latest. Browser validation of the copied archive is recorded separately in `archive-check.json`.


## Opening and adding versions later

Double-click `index.html` in File Explorer, or open it in a browser. Search and category filters run entirely from these files. Each version has labelled links to its student/teacher preview where available; evidence-only collections have screenshot and recording browsers.

For the next design, use a new folder such as `new-versions/11-short-name/`, include its assets and a README with the date and source, then add its labelled links and screenshot to the catalogue and browser index. Keep prior folders unchanged. `families/` contains preserved source snapshots; future work belongs in a new version folder rather than overwriting those snapshots.
