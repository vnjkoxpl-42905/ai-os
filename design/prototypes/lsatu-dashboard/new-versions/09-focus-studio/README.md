## The strongest ideas, carried into one design

| What | What it gives the student | Where the idea came from |
|---|---|---|
| Compact charcoal resume card | One Continue action, exact saved position, twelve countable progress ticks and a task-specific explanation | Lamplight, Margin, Studio and Atmosphere |
| Editorial hierarchy and aligned rows | Readable serif titles, quiet surfaces, useful metadata and clear actions | Broadsheet, Margin, Refined and Refined Studio |
| Work search and filters | LR/RC, status, assigned dates and progress, with honest empty states | Studio and Refined Studio |
| Connected coaching | Task-linked message, unread state, retained reply draft, next session and preparation note | Carrel, Marginalia, Lumen and Refined |
| Question finder | Typed exact reference, sample chips, partial search, LR/RC and All/Saved/Recent collections | Studio and Refined Studio |
| Question-linked Review | Five unique questions, exact result links, missed-only view and shared3/5 totals | Refined Studio and Meridian |
| Selected-day calendar | Event words, keyboard navigation and a day-specific agenda | Lumen and Refined |
| Teacher context | Searchable sample roster, student work context and assignment draft preview | Carrel and the original role handoff |
| Restrained motion | Stable navigation, short content transitions, no repeated heading animation on filters and reduced-motion support | Motion studies and LexPrep refinements |

These are lineages from the [adoption review](../../../../../research/2026-10-24-dashboard-adoption-review/REPORT.md), not verified authorship claims about every historical file. The current selected Home structure stays compact; the finder and results live in their own destinations.

## Open it without a build step

Open index.html directly in a browser. Fonts, artwork, styles and scripts are local. The archive and09 exact lookup were tested with browser networking offline. A temporary preview is also available at http://127.0.0.1:5200/ while its local server remains running.

All people, schedules, questions and results are demonstration data. The calendar is deliberately frozen to2026-10-24 through2026-10-30. Review is fixed demonstration history; practicing a sample does not create a new historical result. Browser-local notes, drafts and bookmarks are not signed-in or cross-device storage. Teacher drafts do not send or assign anything.
